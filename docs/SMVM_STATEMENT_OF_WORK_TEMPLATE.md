# Statement of Work — business/legal review template

Not an accepted contract. Complete with the verified merchant and customer before signing; do not infer an agreement from a website enquiry.

| Item | Required agreement |
| --- | --- |
| Parties / authority | Legal merchant, structure, address, customer legal name, authorized representatives and email notices |
| Project / version | Unique proposal reference, date, version, validity and written acceptance mechanism |
| Scope | Deliverables, exclusions, functional and technical requirements; applicable platforms and dependencies |
| Milestones | Deliverable, responsible party, target, customer dependencies and acceptance evidence for each milestone |
| Acceptance | Objective tests, review period agreed by both parties, rejection/remediation and disputed acceptance process |
| Price | INR base, taxes after GST review, total, advance, milestone amounts, due dates and expressly approved expenses |
| Change control | Written impact assessment and mutual approval of scope, price and time before extra work |
| Revisions | Agreed number/type if limited, distinction between defects and scope changes |
| Third parties | Who buys/owns domain and hosting accounts, renewal costs, provider constraints and licenses |
| Confidentiality / data | Permitted purposes, authorized access, secure exchange, processors, retention, deletion, breach response |
| Intellectual property | Pre-existing IP, new deliverable ownership/license, timing of transfer, third-party exclusions |
| Handover | Source code if agreed, repository access, credentials via secure channel, documentation, build/deploy instructions and training |
| Maintenance | Covered versions, fixes versus enhancements, support hours/targets, term, fees and exclusions |
| Delays | Notice, dependency handling, revised plan, escalation and remedies |
| Cancellation / refund | Before/after commencement, value of accepted work, undelivered milestones, approved unavoidable expenses, fair itemized calculation |
| Disputes / liability | Qualified legal review; preserve mandatory remedies; no copied venue or blanket exclusion |
| Policy linkage | Exact accepted terms/refund/privacy versions, any negotiated precedence and immutable signed copy |

Record affirmative acceptance by authorized representatives, the accepted version and timestamp in the actual contract system. This template creates no payment obligation or order record by itself.
