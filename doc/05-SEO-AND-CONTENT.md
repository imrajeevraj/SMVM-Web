# SMVM Web Portal — SEO & Content Plan

## Primary SEO Objectives

1. Make SMVM discoverable as a software company.
2. Make product pages discoverable.
3. Build clear topical relevance.
4. Make pages understandable to search engines and humans.
5. Maintain excellent technical SEO.

## URL Map

```text

/products

/about
/vision
/contact
/privacy
/terms
```

## Metadata Template

### Home

```text
Title:
SMVM Software | [Approved Brand Positioning]

Description:
[Clear factual description of SMVM and its software products.]
```

### Products

```text
Title:
SMVM Software Products | [Approved Product Category]

Description:
Explore software products from SMVM Software, including CamBill POS.
```

### CamBill POS

```text
Title:
CamBill POS | [Approved Product Positioning] | SMVM Software

Description:
[Accurate product description based on actual features.]
```

Do not publish invented feature claims.

## Keyword Strategy

Research before final copy:

```text
SMVM Software
SMVM Software products
CamBill POS
camera shop POS
camera store inventory software
camera store billing software
inventory and billing software
```

Use only keywords supported by actual product positioning.

## Internal Linking

Home → Products

Products → Product Detail

Product Detail → Contact

About → Vision

Vision → Contact

Footer → all major pages

## Schema

Organization:

```json
{
  "@type": "Organization",
  "name": "SMVM Software"
}
```

Product pages may use Product schema only when the page contains valid product information.

## Sitemap

Include only canonical indexable pages.

## Robots

Allow public pages.

Do not accidentally expose:

```text
/admin
/api
private test routes
```

if they exist.

## Content Quality

Every page should answer:

```text
What is this?
Who is it for?
Why does it matter?
What can the visitor do next?
```
