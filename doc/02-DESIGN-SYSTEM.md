# SMVM Web Portal — Design System

## Brand Direction

**Positioning:** Modern business software with a practical technology-first identity.

### Visual Keywords

```text
Modern
Technical
Clean
Trustworthy
Premium
Human
Efficient
Innovative
```

## Color System

Do not finalize exact brand colors until the approved SMVM logo/brand kit is inspected.

Use semantic tokens:

```css
--color-bg
--color-surface
--color-surface-elevated
--color-text
--color-text-muted
--color-brand
--color-brand-strong
--color-accent
--color-border
--color-success
--color-warning
--color-danger
```

Create light and dark values for every semantic token.

## Spacing

Use a consistent spacing scale:

```text
4
8
12
16
24
32
40
48
64
80
96
128
```

## Radius

Use restrained radii:

```text
small controls: 8
cards: 12–16
large feature surfaces: 20–24
pills: 999
```

Do not make every element pill-shaped.

## Shadows

Prefer subtle elevation:

```text
shadow-sm
shadow-md
shadow-lg
```

Use shadows to establish hierarchy, not decoration.

## Buttons

Primary:

```text
Brand background
High contrast text
Clear hover
Visible focus
```

Secondary:

```text
Transparent / surface
Visible border
```

Ghost:

```text
Minimal chrome
```

All buttons need disabled and loading states where relevant.

## Cards

Card anatomy:

```text
Icon / eyebrow
Title
Description
Optional metadata
CTA
```

Cards should not become walls of text.

## Product Visuals

Use:

```text
Browser mockup
Desktop app frame
Phone frame
Screenshot gallery
Video
```

Only use the frame when it improves presentation.

## Motion

Motion should be:

- short
- subtle
- purposeful

Respect reduced motion.

## Dark Mode

Dark mode is not simply black.

Use:

```text
dark background
elevated surface
slightly brighter border
high-contrast text
controlled brand accents
```

Test every image against both themes.
