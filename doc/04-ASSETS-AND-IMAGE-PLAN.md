## Image Rules

Before committing an image:

```text
[ ] correct subject
[ ] correct dimensions
[ ] compressed
[ ] appropriate format
[ ] descriptive filename
[ ] alt text written
[ ] no unnecessary metadata
```

## Recommended Formats

```text
SVG — logos/icons
AVIF — large photographic/complex images where supported
WebP — general web images
PNG — transparency or source assets where needed
MP4/WebM — product demo video
```

## Icon Rules

Use one main icon library.

Recommended:

- Lucide
- Phosphor

Custom icons only where brand identity requires them.

## Chatbot Icon

Use the approved SMVM Memo/chatbot asset.

Design requirement:

- no unwanted circular boundary
- transparent background
- free-flowing visual
- subtle animation
- clear hover/focus state
- accessible label

## Image Generation Briefs

If original graphics need to be generated, create:

1. Abstract software/data hero background.
2. CamBill POS isometric product composition.
3. SMVM technology abstract illustration.
4. Vision/future technology illustration.
5. Minimal decorative technical patterns.

Do not generate fake customer photos or fake testimonials.
